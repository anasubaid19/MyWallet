Selamat Datang di DompetKu!

Aplikasi pencatatan keuangan pribadi offline yang aman, cepat, dan tanpa iklan.

Petunjuk Pemakaian

Cara Install (iPhone / iOS)

  1. Buka aplikasi Safari.
  2. Ketuk ikon Share (Bagikan) di tengah bawah layar.
  3. Pilih "Add to Home Screen".
  4. Ketuk "Add" di pojok kanan atas.

Cara Install (Android)

  1. Buka browser Chrome.
  2. Ketuk ikon Tiga Titik di pojok kanan atas.
  3. Pilih "Tambahkan ke Layar Utama" atau "Install App".

Backup & Restore Data

  • Backup: Pengaturan > Export Data > File JSON.
  • Restore: Pengaturan > Import Data > Pilih file JSON.
